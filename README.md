# Твоё Время. Сайт студии массажа в Минске

Статический сайт: HTML, CSS и немного JavaScript. Без Node, без базы, без сборщиков.
Онлайн-запись встроена прямо в страницу и работает на вашем YCLIENTS.

## Важно: где лежит проект

Проект живёт в `~/Downloads/Massage` и находится под git.

**Не переносите папку в iCloud Drive.** Раньше проект лежал там, и iCloud потерял
часть файлов: пропали генератор, все стили, весь JavaScript и половина страниц.
Папку, в которую часто пишут, iCloud обрабатывает плохо. Для синхронизации между
устройствами используйте git, а не облачную папку.

Сохранить текущее состояние:

```bash
cd ~/Downloads/Massage && git add -A && git commit -m "что изменил"
```

Посмотреть историю и вернуться к любому состоянию:

```bash
git log --oneline
git checkout <хеш>
```

Резервная копия того, что уцелело после сбоя, лежит в `~/Downloads/Massage-backup`.
Её можно удалить, когда убедитесь, что всё на месте.

## Правило про тексты

**Формулировки студии не переписываются.** Всё, что было написано вами на Tilda,
в Instagram, в описаниях услуг YCLIENTS и в карточке Яндекс Карт, стоит на сайте
дословно, вместе с вашей пунктуацией. Дописывать можно, менять нельзя.

Дословно перенесены: первый экран, все пять пунктов «Почему у нас спокойно»,
строка про выбор направления в услугах, описания всех программ, абонементы
и сертификаты, блок контактов, «Новое пространство. Теплый свет. Мягкость.
Покой. Забота», ответы про стеснение, про боль и про выбор процедуры.

Мой текст добавлен только там, где у студии его не было: показания к процедурам,
как проходит сеанс, сколько нужно сеансов, противопоказания, как добраться,
описание парного массажа.

## Как редактировать

Тексты, цены и описания лежат в одном файле `content.py`. После правки:

```bash
python3 build.py
```

Все 13 страниц пересобираются за секунду, шапка, подвал и микроразметка обновляются
везде сразу. Править сам HTML тоже можно, но при следующей сборке правки затрутся.

## Как посмотреть локально

```bash
cd ~/Downloads/Massage && python3 -m http.server 4611
```

Открыть http://localhost:4611. Локальный сервер обязателен: ссылки на страницы
абсолютные, через двойной клик по файлу сайт откроется неправильно.


Когда купите настоящий домен, префикс не нужен, собирайте обычной командой
`python3 build.py`, предварительно поправив `domain` в `content.py`.

## Как выложить на свой домен

Любой статический хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages,
обычный хостинг по FTP. Копируете содержимое папки в корень сайта.

После покупки домена поменяйте одну строку в `content.py`:

```python
"domain": "https://tvoye-vremya.by",
```

и пересоберите. Адрес подставится в canonical, Open Graph, sitemap, robots
и микроразметку.

## Онлайн-запись

Форма YCLIENTS встроена через iframe и связана с расписанием напрямую.

- **`/zapis/`** содержит форму на весь экран. На телефоне она занимает высоту
  экрана целиком, чтобы не было двух вложенных прокруток.
- **Главная** содержит ту же форму в блоке «Записаться онлайн».
- **Остальные страницы** не тянут сторонний iframe, вместо него блок с кнопкой.
- Форма грузится при подходе к ней, но не позже трёх секунд.

### Услуга подставляется в форму сама

```
кнопка на сайте     /zapis/?u=svoboda-dvizheniya,limfodrenazhnyy
форма YCLIENTS      ...select-services?o=s29161668s30395139
```

Услуг можно передать несколько через запятую: YCLIENTS сложит их в один визит
и сам посчитает время и сумму.

ID услуг лежат в `content.py` в поле `yid`. **Если пересоздадите услугу
в YCLIENTS, ID изменится.** Взять новый: откройте форму записи, отметьте услугу
и посмотрите в адресную строку, там будет `?o=s<ID>`.

**Проверьте:** на старой Tilda использовались два адреса YCLIENTS, `n2200455`
и `n2181051`. Оба открывают одну студию с одинаковым прайсом. Сейчас стоит первый.

## Технические заметки

- **Mobile first.** Базовые правила описывают телефон, медиазапросы через
  `min-width`: 600, 900, 1080, 1200 px. Кнопки не меньше 48 px, на телефоне
  закреплена нижняя панель.
- **Одна сетка.** Контейнер максимум 1280 px. Новый блок кладём внутрь `.wrap`
  и не задаём ему боковых отступов.
- **Тема тёмная и зафиксированная**: съёмка и печатные материалы студии сделаны
  при приглушённом свете.
- **Контраст.** Все сочетания текста и фона проходят WCAG AA, минимум 4,79:1.
  `--gold-deep` только для рамок и иконок, для текста всегда `--gold-text`.
- Шрифты локальные. Внешних запросов нет, кроме формы записи и карты,
  обе грузятся лениво.
- Анимации на IntersectionObserver, обработчиков `scroll` нет.
  При настройке «уменьшить движение» отключаются.
